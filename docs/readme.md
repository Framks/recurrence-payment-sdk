# Documentação

Ordem de leitura sugerida:

1. [`criterios.md`](criterios.md) — os critérios que decidem se um campo ou
   operação entra no modelo canônico. Leia primeiro: é o filtro usado para
   escrever `modelo-canonico.md`.
2. [`modelo-canonico.md`](modelo-canonico.md) — o contrato em si
   (`com.recurrence.contract`), descrito como implementado hoje: tipos,
   services, mapas de estado por provedor e a matriz de rastreabilidade.
   A seção 12 lista as pendências e divergências conhecidas entre o
   documento e o código — comece por ali se for mexer no contrato.
