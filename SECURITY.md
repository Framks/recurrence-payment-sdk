# Política de segurança

Esta biblioteca lida com credenciais de provedores de pagamento e dados de assinaturas.

## Como reportar uma vulnerabilidade

**Não abra issue pública.** Use o reporte privado do GitHub:
<https://github.com/Framks/recurrence-payment-sdk/security/advisories/new>.

Inclua a versão afetada, o provedor (PagBank / Mercado Pago) e os passos para reproduzir,
**sem** tokens ou dados reais.

## Versões suportadas

Só a versão mais recente publicada recebe correções de segurança.

## Credenciais vazadas

Se você publicou um token por engano (em issue, PR ou log), revogue-o imediatamente no
painel do provedor. Apagar a mensagem não basta.
